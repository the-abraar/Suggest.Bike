# Japanese brands in Bangladesh: timeline

Access date 2026-10-13. Only verified items; "?" = unknown.

| Year | Event | Source |
|---|---|---|
| 1980-86 | Honda H100/H100A already on roads; H100S reached BD early 1986 (importer unknown) | [BikeBD](https://bikebd.com/blog/honda-h100s-cdi) |
| 1980s-90s | Kawasaki via unofficial individual imports only | [BikeBD](https://www.bikebd.com/brand/kawasaki) |
| 2012/13 | Rancon Motor Bikes (Rangs) begins Suzuki distribution; first shipment summer 2013 | [Suzuki BD](https://suzuki.com.bd/about) |
| Aug 2013 | Suzuki-Rancon CKD assembly deal announced; Honda-BSEC assembly in preparation | [Daily Star](https://www.thedailystar.net/news/suzuki-teams-up-with-rancon-to-assemble-motorcycles) |
| 2013 | Bangladesh Honda (Honda 70% / BSEC 30%) starts CD80 CKD assembly, Gazipur | [Dhaka Tribune](https://www.dhakatribune.com/amp/business/commerce/234204/honda-s-signifies-remarkable-journey-in-bangladesh) |
| Aug 2015 | Rancon Suzuki flagship showroom; Gazipur assembly unit | [Daily Star](https://www.thedailystar.net/node/131485) |
| 2016 | Yamaha enters BD via ACI Motors (CBU imports from India) | [Daily Star](https://d11.thedailystar.net/business/organisation-news/news/yamaha-celebrates-8-years-aci-motors-3755041) |
| 2018 | BHL own plant, Munshiganj; Suzuki own Gazipur plant (per Suzuki); Kawasaki official start with Asian Motorbikes (BikeBD claim) | [Dhaka Tribune](https://www.dhakatribune.com/amp/business/commerce/234204/honda-s-signifies-remarkable-journey-in-bangladesh), [Suzuki](https://suzuki.com.bd/about), [BikeBD](https://www.bikebd.com/brand/kawasaki) |
| 2018 | Yamaha FZS FI V2 Dual Disc booking 1 May, Tk 265,000 | [BikeBD](https://www.bikebd.com/blog/aci-motors-launch-yamaha-fzs-fi-v2-bangladesh) |
| 1 Jul 2020 | Suzuki 2019 Gixxer / Gixxer SF launched | [TBS](https://www.tbsnews.net/node/100465) |
| late 2020 | Honda Dream 110 (Tk 89,900); BHL 200k units | [Dhaka Tribune](https://www.dhakatribune.com/amp/business/commerce/234204/honda-s-signifies-remarkable-journey-in-bangladesh) |
| 2022? | Kawasaki Ninja 125 / Z125 launch | [BikeBD](https://bikebd.com/blog/kawasaki-ninja-125-launched-bangladesh) |

Gaps: 1960s-70s Japanese/European imports, 1990s-2012 Honda/Yamaha/Suzuki importers (RX100/RX135, CD70, CG125, Max100), BD assembly status of Yamaha. No source found.
