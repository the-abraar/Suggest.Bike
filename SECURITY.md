# Security policy

Suggest.Bike is a static site (GitHub Pages) with no accounts, logins or backend. It holds no personal data beyond what your own browser stores.

## Reporting a problem

Please report security problems privately, not in a public issue:

- **Preferred:** [open a private security advisory](https://github.com/the-abraar/Suggest.Bike/security/advisories/new) on this repo.
- **Or email** hello@suggest.bike.

Include the URL, what you did, and what happened. Please give us a fair chance to fix the problem before you disclose it.

## Scope

The site at https://suggest.bike and the code in this repo. The same contacts are published at https://suggest.bike/.well-known/security.txt.
